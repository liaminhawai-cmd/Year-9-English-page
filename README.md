# Year 9 English · pages

Student-facing pages for Year 9 English. Static HTML, no build step.

- `curious-incident/` — Speaking and Listening Folio for *The Curious Incident
  of the Dog in the Night-Time*: prompts and display timer, WAGOLL wall,
  rubric, group shuffler, printable booklet.

To publish: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.

See `AGENTS.md` before changing anything.
